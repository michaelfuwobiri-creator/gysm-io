## Description (4000 char max)
GYSM turns a plain-English description into a real, working app — not a
mockup, not a template. Say what you want to build and GYSM generates
production code with authentication, a database, and payments already
wired in.

HOW IT WORKS
• Describe your app idea in a sentence or two
• GYSM generates working code with a live preview
• Keep iterating in the app — refine features, tweak design, add pages
• Export the code, deploy it yourself, or publish to BuildGuild

WHAT'S INCLUDED IN EVERY BUILD
• User authentication, ready to go
• A real database, not a mock
• Payment integration for subscriptions or one-time purchases
• A live, working preview — not a static screenshot

BUILDGUILD
Publish what you build to BuildGuild, GYSM's public showcase, and see
what other founders and indie hackers are shipping.

WHO IT'S FOR
Founders validating an idea, freelancers prototyping for clients, and
indie hackers who want to go from idea to working product without
writing boilerplate.

Credits are used per build. Subscriptions renew monthly and include a
monthly credit allowance; one-time credit packs never expire.

## Screenshots needed (per required iOS device size)
Reuse the same four Play Store captures (builder_live, buildguild,
homepage, social_proof) reformatted to Apple's required sizes:
- 6.9" display (iPhone 16 Pro Max class): 1320 x 2868
- 6.5" display (iPhone 14 Plus class): 1284 x 2778 or 1242 x 2688
- iPad 13" (if supporting iPad): 2064 x 2752
At minimum the 6.9" set is required; Apple auto-scales down for smaller
iPhones if only the largest size set is uploaded, but uploading the 6.5"
set too avoids any letterboxing on older device previews.
